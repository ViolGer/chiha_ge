Распаковать поверх папки `ka_trainer`. Проверка, что легло правильно (должно быть `True`):

```powershell
Test-Path trainer\audio.py, generate_audio.py, trainer\course.py
```

Запуск как обычно:

```powershell
venv\Scripts\python.exe manage.py runserver
```

Миграции и `load_vocab` не нужны — база не менялась.

## 1. Транскрипция в играх

**Составь предложение.** Под каждой грузинской фишкой — транскрипция мелким шрифтом.
Когда задание на грузинском, под фразой появляется транскрипция всей фразы. В обратную
сторону (задание по-русски, собираешь грузинскую фразу) транскрипция фразы намеренно
не показывается — она выдала бы порядок слов в ответе. Подсказка по клику осталась
как была, плюс к ней теперь всегда видно чтение.

**Пары слов.** Под каждым грузинским словом в левом столбике — транскрипция.

**Карточки.** Там транскрипция уже была под каждым вариантом, оставила как есть.

Транскрипция берётся выверенная из словаря, а для форм, которых в словаре нет, —
собирается посимвольно.

## 2. Главная страница — разделы сворачиваются

Разделы курса («Как буквы запоминаются сами», «Тренировочная площадка», комиксы,
видео и т. д.) свёрнуты в аккуратные строки-кнопки. Открыт только первый раздел —
«Тропа». Клик по строке разворачивает раздел, повторный клик сворачивает.

- Пункты верхнего меню разворачивают нужный раздел и прокручивают к нему.
- Под разделами кнопка «Развернуть все разделы» / «Свернуть все разделы».
- Какие разделы открыты — запоминается в браузере, при следующем заходе всё как оставила.

Важно: содержимое разделов не переносится и не переписывается, а просто заворачивается
в контейнер. Поэтому весь остальной скрипт страницы (тропа, квизы, комиксы, прогресс)
продолжает работать как раньше.

## 3. Озвучка

**Почему молчала.** Страница пользовалась встроенным в браузер синтезом речи и просила
у него грузинский голос (`ka-GE`). В Windows такого голоса в системе обычно нет вообще,
и браузеру просто нечем произнести — кнопка нажимается, но звука нет.

**Как теперь.** Произношение генерируется заранее — тем же бесплатным `edge-tts`
и тем же голосом `ka-GE-EkaNeural`, что в Telegram-боте, — и раздаётся сайтом как
обычные mp3. Если файла для какого-то слова нет, страница тихо откатывается на старый
браузерный синтез: хуже, чем было, не станет.

Один раз нужно сгенерировать файлы у себя:

```powershell
venv\Scripts\python.exe -m pip install edge-tts
venv\Scripts\python.exe generate_audio.py
```

Это озвучит всё грузинское со страницы курса — **160 фрагментов**, включая отдельные
буквы алфавита. Минута-две. Файлы лягут в `trainer/static/trainer/audio/`.

Дополнительно, если захочешь озвучить и тренажёр:

```powershell
venv\Scripts\python.exe generate_audio.py --words       # + все слова словаря (~1900)
venv\Scripts\python.exe generate_audio.py --sentences   # + 160 учебных фраз
venv\Scripts\python.exe generate_audio.py --all         # всё сразу
```

Скрипт можно запускать повторно — уже готовые файлы он пропускает.

⚠️ **Папку с озвучкой нужно закоммитить в git** — иначе на сервере её не будет.
`.gitignore` этому не мешает, `git add -A` подхватит. Полный набор (~2200 файлов)
весит порядка 20 МБ — для git и Render это нормально.

Кнопки озвучки в самих играх тренажёра пока нет — скажи, если нужна, добавлю.

## 4. Ссылка на бота

В `trainer/course.py`, сверху, есть строка:

```python
BOT_URL = ""
```

Впиши туда адрес бота (`https://t.me/имя_бота`) — и на курсе появятся пункт меню
«🤖 Бот в Telegram» и карточка перед подвалом страницы. Пока строка пустая, ничего
не показывается. Скажи адрес — впишу сама, если удобнее.

## Проверено браузером

Разделы: 10 штук, свёрнуты кроме первого, клик по пункту меню разворачивает нужный,
«развернуть все» открывает все 10, состояние переживает перезагрузку, прогресс-галочки
на тропе продолжают сохраняться. Игры: в парах транскрипция у всех 6 плиток, в
предложениях — у всех фишек. Озвучка: кнопок на странице 107, при нажатии уходит запрос
за файлом; когда файл есть — приходит 200 и звук играет, когда нет — 404 и тихий откат
на браузерный синтез, ошибок в консоли нет.
