# Тренажёр слов — «Грузинский с нуля»

Django-приложение с 4 играми для изучения грузинской лексики: составление предложений,
пары слов на время, карточки-эмодзи, тренажёр по буквам. Очки за урок и накопительный счёт
хранятся в базе данных, привязаны к браузеру (без регистрации).

## Что внутри

- **~1900 грузинских слов** с переводом, транскрипцией, частью речи и темой
- **160 учебных предложений** для игры «составь предложение»
- **291 слово с эмодзи** для игры-карточек
- **33 буквы** грузинского алфавита для тренажёра произношения

## Локальный запуск (для проверки на своём компьютере)

Нужен Python 3.11+.

```bash
python -m venv venv
source venv/bin/activate        # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py load_vocab     # загружает слова/предложения в базу
python manage.py runserver
```

Открыть http://127.0.0.1:8000/

## Как разместить сайт в интернете (бесплатно)

Сам по себе Django-проект — это просто код, ему нужен постоянно работающий сервер, чтобы
по нему открывалась ссылка. Проще всего — Render.com: бесплатный тариф, не требует
банковской карты, разворачивает проект прямо из GitHub.

### Вариант 1 — Render.com (рекомендую, проще всего)

1. Зарегистрируйся на https://render.com (можно через GitHub-аккаунт).
2. Залей эту папку в свой репозиторий на GitHub (Render разворачивает сайт из Git-репозитория).
   Если раньше не работала с git — самый простой способ: создать новый пустой репозиторий на
   github.com, а дальше открыть эту папку в VS Code или GitHub Desktop и нажать «Publish repository».
3. В Render: New → Web Service → выбрать этот репозиторий.
4. Render сам увидит `requirements.txt` и `Procfile` и предложит правильные настройки
   (Build Command: `pip install -r requirements.txt`, Start Command уже указан в Procfile).
5. Добавить переменную окружения `DJANGO_DEBUG=0` и `DJANGO_SECRET_KEY` (любая длинная случайная
   строка) в разделе Environment.
6. Нажать Create Web Service — через пару минут появится постоянная ссылка вида
   `https://твой-проект.onrender.com`.

**Особенность бесплатного тарифа Render:** если сайтом не пользуются 15 минут, сервер «засыпает»
и следующий заход занимает около минуты, пока он «просыпается». Для тренажёра для себя/учеников
это не критично. Бесплатно даётся 750 часов работы сервера в месяц — на один сайт хватает с запасом.

### Вариант 2 — PythonAnywhere

Тоже бесплатный вариант, без «засыпания», но настройка чуть более ручная (через их веб-интерфейс,
без привычного git-деплоя). Подходит, если Render не понравится. Гайд: любой поиск
"deploy django to pythonanywhere" — шаги стандартные, база данных (SQLite) уже входит в проект,
ничего дополнительно настраивать не нужно.

### После деплоя

Один раз выполнить (Render делает это автоматически при каждом деплое благодаря строке `release:`
в Procfile — она уже настроена):

```bash
python manage.py migrate
python manage.py load_vocab
```

## Админка

По адресу `/admin/` — можно просматривать и редактировать слова/предложения. Чтобы зайти,
один раз создать администратора:

```bash
python manage.py createsuperuser
```

## Структура проекта

```
config/           — настройки Django
trainer/
  models.py       — Word, Sentence, GameResult
  views.py        — страницы и JSON API для игр
  game_data.py    — данные по буквам алфавита
  data/           — исходные json/txt со словами и предложениями
  management/commands/load_vocab.py — загрузка данных в базу
  templates/       — HTML-шаблоны
  static/trainer/  — CSS и JS игр
```
