# Проект «Грузинский с нуля» — сайт-курс + тренажёр слов (спецификация)

Общий контекст проекта: что сделано, как устроено, что дальше.

## Из чего состоит

- **Сайт-курс «Тропа к грузинскому»** — `georgian_trail.html`, один файл (~600 КБ,
  весь CSS и JS внутри, фото маскота — data-URI). Изначально публиковался как
  Claude Artifact.
- **Django-приложение `ka_trainer/`** с играми, задеплоено на Render.com из GitHub.
- **Telegram-бот «Грузинский с нуля»** (aiogram, отдельный проект — см.
  `georgian_bot_context.md`). Общий с сайтом маскот Чиха и тот же голос озвучки.

Курс и тренажёр объединены в один сайт:

- `/` — курс «Тропа к грузинскому»
- `/trener/` — тренажёр со списком игр
- `/igra/...`, `/api/...`, `/ozvuchka/`, `/admin/` — внутренние адреса

## Как устроен курс внутри Django

Файл курса лежит в `trainer/site/georgian_trail.html` и отдаётся вью `trainer/course.py`.
Он **не** шаблон Django: код его не разбирает, а отдаёт как есть, делая на лету
точечные правки по тексту:

1. оборачивает в полноценный HTML-документ (в артефакте `<!doctype>`, `<head>`, `<body>`
   добавлялись автоматически, поэтому в самом файле их нет);
2. дописывает ссылки на тренажёр — пункт меню и плавающая кнопка; при заполненном
   `BOT_URL` — ещё пункт меню и карточку со ссылкой на бота;
3. **чинит сохранение прогресса**: в артефакте галочки сохранялись через
   `window.claude.use("artifact").publish(...)`, вне claude.ai этого механизма нет —
   вью подменяет его на `localStorage` (ключ `georgian_trail_progress_v1`);
4. **сворачивает разделы в «гармошку»**: содержимое каждой `<section id=…>`
   заворачивается в контейнер и прячется, заголовок превращается в кнопку. Разметка
   не переносится и не удаляется, поэтому родной скрипт страницы продолжает находить
   свои элементы. Открытые разделы запоминаются в `localStorage`;
5. **переключает озвучку** с браузерного синтеза на заранее сгенерированные файлы
   (см. ниже), с откатом на синтез, если файла нет.

Собранная страница кэшируется в памяти процесса. Чтобы обновить курс, достаточно
положить новый `georgian_trail.html` на то же место — `course.py` править не нужно.
Если якорь для замены не найдётся, страница всё равно откроется, просто без
соответствующей мелочи.

## Данные тренажёра

`trainer/data/`, загружаются командой `manage.py load_vocab`:

- `words.json` — 1891 слово: грузинское, транскрипция, перевод, часть речи, тема.
- `words_extra.json` — 28 базовых слов, которых не оказалось в основном наборе
  (проверка по ядру частотной лексики: из 61 слова отсутствовали 26 — `დღე` день,
  `ღამე` ночь, `დილა` утро, `გამარჯობა` здравствуй, `კაცი` мужчина, `ქალი` женщина,
  `ხილი` фрукты, `თბილისი` Тбилиси, `ქართული` грузинский и др., при том что
  `ღამურა` летучая мышь и `სადღეგრძელო` тост в базе были).
- `emoji_words.json` — 291 слово с эмодзи для игры-карточек.
- `word_forms.json` — 170 форм из учебных предложений с переводами (см. подсказки).
- `sentences.txt` — 160 учебных фраз.

(апостроф — абруптивные კ ტ პ წ ჭ ყ; обычные т/к/п/ч/ц — придыхательные თ/ქ/ფ/ჩ/ც).

## Игры

1. **Составь предложение** — RU↔KA, фразы из базы. Под каждой грузинской фишкой
   транскрипция; когда задание на грузинском — транскрипция всей фразы (в обратную
   сторону не показывается, чтобы не выдать порядок слов). Клик по слову — перевод.
2. **Пары слов** — 6+6 слов, таймер 2 минуты, под грузинскими словами транскрипция.
3. **Карточки** — эмодзи + русское слово, выбрать грузинское из 4 вариантов
   (под каждым транскрипция).
4. **Буквы** — грузинская буква, выбрать чтение из 4 вариантов.
5. **Статистика** — очки за урок и накопительный счёт в базе, привязка к сессии
   браузера, кука на год. Прогресс курса — отдельно, в localStorage.

## Подсказки перевода (`trainer/word_hints.py`)

Порядок поиска: точное совпадение со словарём → `word_forms.json` (вручную выписанные
переводы всех форм из предложений) → отсечение окончаний (`-ში`, `-ზე`, `-ს`, `-დან` …)
и поиск основы, такой перевод помечается как приблизительный → только транскрипция.
Покрытие учебных предложений: было 212 из 446 слов (48%), стало 446 из 446.

## Озвучка (`generate_audio.py` + `trainer/audio.py`)

Браузерный синтез для грузинского в Windows не работает — голоса `ka-GE` в системе
нет. Поэтому произношение генерируется заранее через бесплатный `edge-tts` голосом
`ka-GE-EkaNeural` (тот же, что в боте), файлы лежат в `trainer/static/trainer/audio/`,
имя файла — хэш от нормализованного текста, раздача через `/ozvuchka/?w=…`.
По умолчанию скрипт озвучивает всё грузинское со страницы курса (160 фрагментов,
включая отдельные буквы); флаги `--words` (~1900 слов) и `--sentences` — по желанию.
Скрипт идемпотентный. Файлы нужно коммитить в git, иначе на сервере озвучки не будет.

## Деплой

Render.com, бесплатный тариф, SQLite. Важно:

- Render **не выполняет** строку `release:` из Procfile (это соглашение Heroku),
  поэтому `migrate` и `load_vocab` должны стоять в Build Command:
  `pip install -r requirements.txt && python manage.py migrate && python manage.py load_vocab && python manage.py collectstatic --noinput`
- SQLite на бесплатном тарифе живёт до следующего деплоя или перезапуска: слова
  подгружаются заново при каждой сборке, а накопленные очки обнуляются.
- Бесплатный инстанс засыпает после 15 минут простоя, первый заход после паузы ~минута.
- В проде должны быть переменные `DJANGO_DEBUG=0` и `DJANGO_SECRET_KEY`.

## Особенность работы через чаты

У каждого чата своя облачная песочница. Копия исходников продублирована в Project
Knowledge: `ka_trainer_source.md` (код), `ka_trainer_data.md` (данные),
`georgian_trail.html` (курс), `georgian_bot_context.md` и `georgian_bot_source.md` (бот).

**Важно:** эти копии могут отставать от того, что реально лежит у Виолетты на диске
(так уже было дважды: шаблон карточек без `#feedback`, `game_data.py` без
`transliterate`). Перед заменой файлов лучше свериться с её версией — либо подключить
папку проекта к сессии (кнопка «Add folder» в приложении), либо попросить прислать
конкретный файл.

## Планы на будущее

### Личный кабинет пользователя

Сейчас никакой регистрации нет: прогресс курса лежит в `localStorage` браузера,
очки тренажёра — в базе с привязкой к сессионной куке. Из-за этого прогресс
теряется при смене устройства или чистке браузера, а на бесплатном Render —
ещё и при каждом передеплое.

Что нужно для кабинета:

- регистрация и вход (штатный `django.contrib.auth`, вход по email);
- привязка `GameResult` к пользователю вместо `session_key`, с переносом уже
  накопленного из текущей сессии при первом входе;
- перенос прогресса курса из localStorage в базу, чтобы галочки на тропе были
  общими для всех устройств;
- страница профиля: пройденные темы, очки по играм, стрик, список выученных слов;
- по желанию — вход через Telegram, чтобы связать аккаунт с ботом и свести
  прогресс сайта и бота воедино.

Технический предварительный шаг: **база данных должна пережить передеплой**, иначе
кабинет бессмысленен. Значит SQLite нужно менять на Postgres (на Render есть
бесплатный) — это правка `settings.py` плюс одна зависимость.

## Известные ограничения

- Подсказки для форм, которых нет ни в словаре, ни в `word_forms.json`, показываются
  как приблизительные («похоже на форму слова…») — сознательно, чтобы не выдавать
  догадку за точный перевод.
- Эмодзи есть у 291 слова из 1891 — только там, где соответствие однозначное.
- Прогресс и очки привязаны к браузеру (до появления личного кабинета).
