# Проект «Грузинский с нуля» — тренажёр слов (спецификация)

Этот файл — общий контекст проекта. Его можно прикрепить как файл к Project на claude.ai,
чтобы любой новый чат внутри этого проекта сразу понимал, что уже сделано и что нужно делать дальше.

## Что это вообще такое

Есть основной сайт-курс «Грузинский с нуля»: **georgian_trail.html** — ОДИН html-файл
(весь CSS и JS внутри, фото маскота — data-URI, ~600 КБ). Изначально был опубликован как
Claude Artifact (ссылка: https://claude.ai/code/artifact/5040511a-2c87-4a52-8aee-b7548bcc9c84).

И есть Django-приложение с играми — `ka_trainer/`, задеплоено на Render.com из репозитория
на GitHub.

**Текущее состояние: курс и тренажёр объединены в один сайт на Django.**

- `/` — курс «Тропа к грузинскому» (georgian_trail.html)
- `/trener/` — главная тренажёра со списком игр
- `/igra/...`, `/api/...`, `/admin/` — как было

Как это устроено (сентябрь 2026): файл курса лежит в `trainer/site/georgian_trail.html` и
отдаётся вью `trainer/course.py`. Он **не** шаблон Django — код его не разбирает, а отдаёт
как есть, делая на лету три точечные правки по тексту:

1. оборачивает в полноценный HTML-документ (в артефакте `<!doctype>`, `<head>`, `<body>`
   добавлялись автоматически, поэтому в самом файле их нет);
2. дописывает ссылки на тренажёр — пункт меню «🎮 Тренажёр слов» и плавающую кнопку
   в правом нижнем углу;
3. **чинит сохранение прогресса**: в артефакте галочки на «тропе» сохранялись через
   `window.claude.use("artifact").publish(...)` — вне claude.ai этого механизма нет и
   прогресс терялся бы при перезагрузке. Вью подменяет это на `localStorage`
   (ключ `georgian_trail_progress_v1`), у каждого посетителя свой прогресс в своём браузере.

Собранная страница кэшируется в памяти процесса. Чтобы обновить курс, достаточно положить
новый `georgian_trail.html` на то же место — `course.py` править не нужно; если якорь для
замены не найдётся, страница всё равно откроется, просто без соответствующей мелочи.

В тренажёре обратные ссылки: пункт меню «← К курсу» и ссылка в подвале (`base.html`),
а кнопка после завершения игры ведёт на `/trener/` (правка в четырёх JS-файлах игр).

## Тренажёр: содержание

### 1. База слов
~2000 самых частых грузинских слов. Формат одной строки (pipe-delimited):

```
georgian_word|transcription|russian_translation|part_of_speech_short|theme
```

- `georgian_word` — грузинское слово (Mkhedruli)
- `transcription` — практическая русская транскрипция. Конвенция:
  ა=а ბ=б გ=г დ=д ე=е ვ=в ზ=з თ=т ი=и კ=к’ ლ=л მ=м ნ=н ო=о პ=п’ ჟ=ж რ=р ს=с ტ=т’ უ=у
  ფ=п ქ=к ღ=гх ყ=къ შ=ш ჩ=ч ც=ц ძ=дз წ=ць ჭ=чь ხ=х ჯ=дж ჰ=һ
  (апостроф ’ — абруптивные/эйективные კ ტ პ წ ჭ ყ; обычные т/к/п/ч/ц — придыхательные თ/ქ/ფ/ჩ/ც)
- `russian_translation` — перевод на русский
- `part_of_speech_short` — сущ / гл / прил / нареч / мест / предл / союз / числ / межд / част
- `theme` — тематическая метка (еда, семья, глаголы, и т.д.)

**Статус: готово.** Собрано 13 тематических блоков, смерджено и дедуплицировано по грузинскому слову.
Итог: **1891 уникальное слово** (из ~2325 сырых строк, 434 дубля убраны — многие слова закономерно
попадали в несколько тем, например посуда встречалась и в блоке "еда", и в блоке "быт"). Это чуть
меньше заявленных 2000 — часть слов агенты сознательно пропускали, если не были уверены в точности
перевода (принцип "точность важнее количества" соблюдался на всех этапах). Точечная проверка выборки
(~60 случайных слов) ошибок не выявила. Плюс: 160 учебных предложений и 291 слово с эмодзи-тегом
(для игры-карточек — эмодзи подобраны только для слов с однозначным визуальным соответствием).

Данные лежат в `trainer/data/`, загружаются командой `python manage.py load_vocab`.

### 2. Игра «составь предложение» (Duolingo-style)
Перевод предложений RU→KA и KA→RU (короткие бытовые фразы из слов базы). Клик по слову — всплывающая
подсказка с переводом этого слова.

### 3. Игра «пары слов» (на время)
Два столбика — грузинские слова / русские слова, по 6 слов в столбике, таймер 2 минуты, нужно
за это время составить максимум пар. Столбик закончился — подгружается новая шестёрка,
таймер продолжает тикать.

### 4. Игра-карточки (эмодзи → слово)
Показывается эмодзи, нужно выбрать правильное грузинское слово из 4 вариантов.

### 5. Тренажёр по буквам
Показывается грузинская буква, 4 варианта её произношения русской транскрипцией — выбрать верный.
Данные — `trainer/game_data.py` (LETTERS).

### 6. Статистика
Очки за конкретный урок/сессию игры + накопительный общий счёт. Хранятся в базе Django и привязаны
к сессии браузера (без регистрации), кука живёт год. Прогресс **курса** — отдельно, в localStorage
(см. выше).

### Стилистика
Общие CSS-переменные и визуальный язык с основным сайтом (--bg, --surface, --accent и т.д.,
поддержка светлой/тёмной темы), маскот Чиха (MASCOT_PHOTOS в georgian_trail.html).

## Важное ограничение при разбивке на разные чаты

Если открывать разные чаты/сессии (в т.ч. в рамках одного Project на claude.ai) — у каждого чата СВОЯ
отдельная "облачная песочница" с файлами. Чтобы данные не терялись при переносе между чатами, лучше:

1. Держать этот PROJECT.md актуальным в Project Knowledge — тогда каждый новый чат видит
   спецификацию и текущий статус.
2. Промежуточные результаты (готовые блоки слов, куски кода) — присылать себе файлами и,
   если нужно продолжить в другом чате, прикреплять их туда как вложения.

Исходники приложения продублированы в Project Knowledge: `ka_trainer_source.md` (код),
`ka_trainer_data.md` (данные), `georgian_trail.html` (курс).

## Известные ограничения (честно, как договаривались)

- Подсказка перевода по клику на слово в игре "составь предложение" работает только для слов
  в точной словарной форме — многие слова в предложениях склонены/спряжены, для них подсказка
  покажет "перевод не найден" вместо неточного/неверного варианта. Транскрипция при этом
  показывается всегда (посимвольный фолбэк).
- Эмодзи-теги есть не у всех 1891 слов, только у 291 — эмодзи подбирались только там, где
  соответствие однозначное.
- Прогресс курса и очки тренажёра привязаны к браузеру: на другом устройстве будут свои.
- Бесплатный тариф Render «засыпает» после 15 минут простоя — первый заход после паузы
  занимает около минуты.
- Если на Render в Build Command нет `collectstatic`, обновлённые JS-файлы игр не подхватятся:
  `pip install -r requirements.txt && python manage.py collectstatic --noinput`.
